# ParkMate

A Vehicle Parking Record Manager developed for the
Mobile Application Development practical assignment.

Built using Java and XML layouts in Android Studio.

## Current progress

- Created the Android project.
- Added the Parking Records screen.
- Added the Add/Edit Parking Record screen.
- Added the Parking Details screen.
- Implemented basic navigation between the three screens.

The screens currently contain basic layouts.
Parking data entry and CRUD functionality are still in development.

## Planned functionality

- Add parking records.
- View records and calculated parking fees.
- Update existing records.
- Delete records.
- Track payment status and total collected payments.
- Store records temporarily in memory.
